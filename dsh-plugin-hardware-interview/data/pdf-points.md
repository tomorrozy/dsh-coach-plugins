# PDF 硬件考核点梳理（Taurus 2027 电控组三面）

> 源文件：`Taurus 2027电控组三面.pdf`（共 7 页，8 个阶段 + 进阶拓展）。本文把 PDF 中与硬件相关的条目逐条拆出，并映射到 `checklist.json` 的 H01–H20。编号顺序与 checklist 一致。

## 一、题目总述里的硬件链路

- 系统链路：手带端 MPU6050 →（HC-05 蓝牙 / NRF24L01）→ 小车端 STM32 → TB6612/L298N → 12V 编码器电机。对应 H03、H04、H05、H06、H07、H14。
- 分阶段闯关：低年级完成基础阶段，高年级必须加互补/卡尔曼滤波；滤波虽属算法，但输入质量取决于 MPU6050 的供电、安装与校准。对应 H03、H14。
- 进阶拓展（选做、无阶段限制）：FreeRTOS 调度、CAN 驱动电机、上位机调参；硬件侧新增 CAN 收发器与总线。对应 H15、H19。

## 二、「要求」1–8 中的硬件条目

1. 要求1 独立供电：整套必须电池+降压模块，禁止电脑 USB 供电。→ H01、H02、H20
2. 要求2 无线通信：手带端与小车端用 HC-05 蓝牙或 NRF24L01。→ H04、H05、H11
3. 要求3 自定义协议：帧头 0xA5、帧尾 0x0D（建议 [0xA5][长度][数据][校验][0x0D]）。协议属软件，但链路电平/波特率/共地出错会直接表现为收不到帧头帧尾，是硬件排错抓手。→ H10、H04
4. 要求4 姿态解算：高年级必须互补/卡尔曼滤波，低年级可用简单角度映射；硬件输入是 MPU6050 的 I2C 与安装基准。→ H03、H14
5. 要求5 电机闭环：速度 PID 依赖编码器反馈、驱动板与电源余量。→ H07、H12、H13
6. 要求6 OLED 显示：手势指令、目标速度、实际速度实时显示。→ H08、H17
7. 要求7 VOFA+ 波形：打印目标速度 vs 实际速度，依赖串口/USB-TTL 链路与共地。→ H10、H19
8. 要求8 代码规范：模块化、注释清晰；硬件上体现为分层初始化是否把供电、接口、引脚配对写对。→ H16、H17、H18

## 三、主要物资表（PDF 第 2–4 页）

- 主控 STM32F103C8T6 最小系统板 ×2：双机各一，3.3V、BOOT0/1、SWD、复位与晶振。→ H02、H16
- 传感器 MPU6050（GY-521）：3.3V/5V 供电、I2C 上拉、AD0 地址、安装方向。→ H03、H14
- 无线 HC-05 或 NRF24L01（1 对）：逻辑电平、去耦、天线、配对/频道。→ H04、H05、H11
- 电机 JGB37-520（12V 带编码器）：编码器供电、AB 相上拉、线序、机械安装。→ H07、H13、H20
- 驱动 TB6612 或 L298N：VM/VCC/STBY、PWM 频率、续流与散热。→ H06、H12
- 显示 OLED（SSD1306，I2C/SPI）×2：接口选择、3.3V 供电、地址与上拉。→ H08
- 电源 12V 航模电池+降压模块（12V→5V/3.3V）：供电树、电流能力、共地、电池保护。→ H01、H20
- 其他 按键/LED/面包板/洞洞板/杜邦线：上拉/下拉、限流电阻、接触电阻与走线。→ H09、H18、H20
- 调试 ST-Link 下载器、VOFA+ 上位机：SWD 下载、串口波形观测。→ H19、H10
- 进阶可选 CAN 收发器、支持 CAN 的电机：终端电阻、共地/隔离。→ H15

## 四、八个阶段里涉及硬件的任务

第一阶段（双机通信基础）
- 任务1 串口双向：按键触发发送、OLED 显示电脑发来的内容。→ H16、H09、H08、H10、H19
- 任务2 双机 UART：TX-RX 交叉、共地。→ H10、H02
- 任务3 自定义协议解析：接收端解帧并显示；误码先查电平、波特率、共地。→ H10、H04
- 任务4 UART+DMA 传输：DMA 不改变电气属性，但要求链路稳定。→ H16、H10

第二阶段（电机驱动基础）
- 任务1 PWM 开环调速与正反转：PWM 引脚、频率、驱动供电、启动电流。→ H06、H12、H20
- 任务2 编码器反馈换算转速/位置：AB 相接线、上拉、共地、计数。→ H07、H13
- 任务3 按键切模式与 LED 指示：上/下拉接法、消抖、限流电阻。→ H09、H18
- 任务4 OLED 显示电机状态：I2C 地址、刷新、各模块初始化。→ H08、H17

第三阶段（双机通信控制电机）
- 任务1/2 指令切换目标速度并驱动电机：通信链路 + 驱动板 + 电源跌落。→ H10、H12、H06

第四阶段（蓝牙无线通信）
- 任务1 蓝牙替换有线 UART：HC-05 电平、配对、波特率。→ H04、H11
- 任务2 通信稳定、指令正确执行：天线摆放、遮挡距离、供电噪声。→ H11、H01

第五阶段（MPU6050 与姿态解算）
- 任务1 I2C 通信正常、读到原始数据：上拉、供电、AD0。→ H03、H14
- 任务2 姿态解算：滤波效果依赖原始数据的稳定性与安装基准。→ H03
- 任务3 角度稳定无跳动、yaw 零飘：零偏、温漂、振动是硬件因素。→ H14

第六阶段（手势控制单个电机）
- 任务1/2 手势映射 + 蓝牙下发：IMU 供电与电机端响应。→ H03、H04、H12

第七阶段（速度闭环 PID）
- 任务1 固定目标值：编码器计数与电源稳定是 PID 生效前提。→ H07、H13
- 任务2 目标值可调：通信链路 + VOFA+ 波形观测。→ H10、H19
- 任务3 手势映射目标速度：IMU + 蓝牙 + 闭环三处硬件同时工作。→ H03、H04、H13、H19

第八阶段（手势控制小车）
- 任务1/2 前进后退/差速转向（两个驱动轮即可）：双电机电流、供电余量、接线安全。→ H01、H06、H12、H20

进阶拓展（选做）
- FreeRTOS 调度、CAN 驱动电机、上位机在线调参：CAN 总线硬件与调试链路。→ H15、H19

## 六、PDF 没写死、但评审会追问的硬件空白

1. 降压模块型号与电流：PDF 只说「12V→5V/3.3V」，未指定 LM2596/MP1584/AMS1117；要能给出 5V 与 3.3V 两路电流预算和电机启动时的余量。→ H01
2. TB6612 的 VM（12V 电机）与 VCC（3.3V 逻辑）必须分开供，STBY 要拉高；PDF 只写「TB6612 或 L298N」。→ H06
3. L298N 备选的压降（约 2V）与发热：12V 电机实际只剩约 10V，需解释为什么仍推荐 TB6612。→ H06、H12
4. HC-05 电平细节：模块可 3.6–6V 供电，但 RX 是 3.3V 逻辑；5V 供电时 TX 接近 5V，直连 3.3V MCU 要分压。→ H04
5. NRF24L01 的 3.3V 与去耦：模块对电源噪声极敏感，10µF+0.1µF 就近放置，两端频道/地址/速率一致。→ H05
6. 编码器供电电压：5V 霍尔编码器接 3.3V MCU 时，AB 相上拉、分压/限流是否真的做了。→ H07、H13
7. 共地拓扑：电池地、驱动地、MCU 地、传感器地单点共地，电机大电流回路不能穿过信号地。→ H01、H10、H13
8. 电机端并联 0.1µF 电容、PWM 频率选择（10–20kHz 或 >20kHz）、TB6612 的短路刹车模式。→ H06、H12
9. 电池保护：航模电池无保护板，需要开关、保险丝、防反接（MOS/二极管）与低压报警。→ H20
10. MPU6050 的 AD0 地址、I2C 上拉阻值与速率（100k/400k）、GY-521 板载 LDO 是否按 3.3V 使用。→ H03、H14
11. 两块 OLED 与 MPU6050 共用 I2C 时的地址冲突、总线电容与上拉阻值。→ H08、H03
12. CAN 收发器型号（TJA1050/SN65HVD230）与 3.3V 逻辑、CAN_H/CAN_L 双绞、两端各 120Ω、共地/隔离。→ H15
13. 两块最小系统板各自 LDO 供电时，信号电平与「谁给谁供电」的边界（避免倒灌）。→ H02、H10
14. 面包板不能走电机大电流，洞洞板焊点与正负极绝缘、杜邦线虚接排查。→ H20、H09
15. ST-Link 只做 SWD 下载时目标板应由电池供电，避免 USB 与电池同时供电冲突。→ H02、H19
16. 排错顺序（万用表测电压/通断、示波器看 PWM/串口、逻辑分析仪看 I2C）PDF 未要求，但面试几乎必问。→ H19
